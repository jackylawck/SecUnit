## 繁體中文

**SecUnit (秒換)** 是一個極速、純淨且重視隱私的萬能單位換算工具。專為日常實用與專業需求設計，融合香港在地情境，並即時接駁多個免費公開 API。

🔗 **線上即時體驗**：[https://jackylawck.github.io/SecUnit/](https://jackylawck.github.io/SecUnit/)

### ✨ 核心亮點
- **無廣告 · 零存儲 (Zero Ads & Zero Storage)**：100% 純前端運算，不安裝任何追蹤碼、Cookie 或資料庫，保障極致個人隱私。
- **離線優先 (Offline-First)**：所有基礎物理單位轉換均在本地瀏覽器完成，無網環境下依然極速運作。
- **多外接 API 支持 (Live API Integrated)**：
  1. **全球匯率**：即時對接 Frankfurter API，支援 30+ 國法幣（日圓、歐元、台幣等）。
  2. **香港即時氣候**：接駁香港天文台公開數據（即時溫度、氣壓、濕度）。
  3. **國際即時金價**：動態換算國際金衡盎司 (USD) 與 香港金行兩 (HKD)。
  4. **食材密度庫**：基於 USDA 權威數據，解決烘焙廚房「體積 (Cup/mL) 轉 重量 (g)」物理難題。
  5. **IP 自動定位**：智慧識別使用者國家，優化預設單位。
- **靈活 UI 介面**：提供「常見 / 進階罕見單位」切換開關，兼顧日常簡潔與科學精密需求。

### 📐 支援換算類別
包含 **18 大分類**：重量、匯率、金價、烘焙、長度、面積、容量、溫度、速度、時間、數據、能量、氣壓/壓力、功率/冷氣、車輛油耗、角度、力、扭力。

### 🛠️ 技術棧
- **Frontend**: HTML5, Vanilla JavaScript (ES6+ Modules)
- **Styling**: Tailwind CSS (CDN)
- **Architecture**: SPA (Single-Page Application), Client-Side Computing
- **Standards Compliant**: 遵循 ISO 80000 (SI Base Units) 數學精確定義與 GDPR 數據最小化規範

## English

**SecUnit** is a lightning-fast, ad-free, and privacy-focused universal unit and rate converter. Designed for daily practicality and technical precision, it incorporates local Hong Kong context while seamlessly connecting to live open APIs.

🔗 **Live Demo**: [https://jackylawck.github.io/SecUnit/](https://jackylawck.github.io/SecUnit/)

### ✨ Key Features
- **Zero Ads & Zero Storage**: 100% client-side computing. Zero tracking scripts, cookies, or databases for maximum user privacy.
- **Offline-First Architecture**: All core physical conversions run directly in your browser, working blazingly fast even without internet access.
- **Live Open API Integration**:
  1. **Global FX Rates**: Connected to Frankfurter FX API covering 30+ fiat currencies (JPY, EUR, TWD, GBP, etc.).
  2. **HK Weather Data**: Real-time integration with Hong Kong Observatory (Temperature, Pressure, Humidity).
  3. **Spot Gold Price**: Live conversion between International Troy Ounces (USD) and HK Gold Taels (HKD).
  4. **Ingredient Density DB**: Powered by USDA food database to solve baking volume (Cup/mL) to weight (g) physics.
  5. **IP Location Awareness**: Auto-detects user region for optimal default unit choices.
- **Smart UI Toggle**: Features an "Advanced/Rare Units" toggle to keep the interface clean for daily use while offering scientific/niche units when needed.

### 📐 Conversion Categories
Supports **18 Categories**: Weight, FX Rates, Gold Price, Baking Ingredients, Length, Area, Volume, Temperature, Speed, Time, Data/Bandwidth, Energy, Pressure, Power, Fuel Consumption, Angle, Force, Torque.

### 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript (ES6+ Modules)
- **Styling**: Tailwind CSS (CDN)
- **Architecture**: SPA (Single-Page Application), Client-Side Computing
- **Standards & Governance**: Aligned with ISO 80000 (SI Unit Standards) for math accuracy and GDPR data minimization principles.
