## 繁體中文

**SecUnit (秒換)** 是一個極速、純淨且高度重視隱私的萬能單位換算系統。專為日常實用、科學計算與跨國工作設計，融合香港在地情境，並即時對接 **8 個免費公開 API**。

🔗 **線上即時體驗**：[https://jackylawck.github.io/SecUnit/](https://jackylawck.github.io/SecUnit/)

### ✨ 核心亮點 (V2.0 升級)
- **無廣告 · 零存儲 (Zero Ads & Zero Storage)**：100% 純前端運算，不安裝任何追蹤碼、Cookie 或資料庫，保障極致個人隱私（符合 GDPR / AIGP 規範）。
- **單一檔案極速架構 (Single-File Architecture)**：無需依賴外置 JavaScript 檔案，載入零延遲，徹底解決瀏覽器快取問題。
- **全新 80 國國際時區換算 (World Timezone Converter)**：
  - 支援 80 個全球主要城市/時區。
  - 自動處理 24 小時跨日時間計算（輸入 `14` 自動換算 `14:00`）。
  - 對接 **WorldTimeAPI** 即時獲取該時區的真實系統標準時間。
- **8 大免費公開 API 即時對接**：
  1. **全球匯率**：對接 Frankfurter API，支援 30+ 國法幣。
  2. **加密貨幣**：對接 CoinGecko API，即時換算 **比特幣 (BTC)** 與 **以太幣 (ETH)**。
  3. **國家人文數據**：對接 REST Countries API，選取貨幣時顯示該國**國旗 Emoji、首都與人口數**。
  4. **香港氣候與全球空氣質素**：接駁香港天文台氣溫數據與 Open-Meteo 全球空氣質素數據 (**PM2.5 / AQI 污染指數**)。
  5. **國際即時金價**：動態換算國際金衡盎司 (USD) 與 香港金行兩 (HKD)。
  6. **食材密度庫**：基於 USDA 權威數據，解決烘焙廚房「體積 (Cup/mL) 轉 重量 (g)」物理難題。
  7. **IP 自動定位**：智慧識別使用者國家，優化預設單位。
- **行動裝置優化 (Mobile Friendly)**：原生 `inputmode="decimal"` 喚起手機數字大鍵盤，搭配視覺閃爍提示與進階罕見單位開關。

### 📐 支援換算類別
包含 **19 大分類**：重量、匯率/加密幣、時區 (80國)、金價、烘焙、長度、面積、容量、天氣/氣壓、速度、時間、數據、能量、壓力、功率、車輛油耗、角度、力、扭力。

## English

**SecUnit** is a lightning-fast, ad-free, and privacy-focused universal unit, currency, and timezone converter. Powered by **8 live open APIs**, it combines everyday utility with high-precision scientific calculations.

🔗 **Live Demo**: [https://jackylawck.github.io/SecUnit/](https://jackylawck.github.io/SecUnit/)

### ✨ Key Features (V2.0)
- **Zero Ads & Zero Storage**: 100% client-side execution with zero tracking scripts, cookies, or databases for maximum privacy (GDPR compliant).
- **Single-File Pure Architecture**: Self-contained HTML with zero external script dependencies for bulletproof stability and instant loading.
- **80-Timezone World Clock Converter**:
  - Covers 80 major global cities/timezones.
  - Handles 24-hour time math seamlessly (e.g., enter `14` for `14:00`).
  - Fetches live standard time directly via **WorldTimeAPI**.
- **8 Live Open APIs Integrated**:
  1. **Global FX Rates**: Connected to Frankfurter FX API covering 30+ fiat currencies.
  2. **Crypto Rates**: Integrated with CoinGecko API for real-time **Bitcoin (BTC)** & **Ethereum (ETH)** conversion.
  3. **Country Meta Info**: Powered by REST Countries API showing **Flag Emoji, Capital, and Population** upon currency selection.
  4. **HK Weather & Global Air Quality**: Real-time HK Observatory weather combined with Open-Meteo **PM2.5 / AQI air pollution metrics**.
  5. **Spot Gold Price**: Live conversion between Troy Ounces (USD) and HK Gold Taels (HKD).
  6. **USDA Food Density DB**: Solves baking volume-to-weight physics (Cup/mL to grams).
  7. **IP Geo-location**: Auto-detects user region to set intelligent default choices.
- **Mobile-First UX**: Equipped with `inputmode="decimal"` to trigger phone numeric keypads instantly, plus visual flash updates for dropdown toggles.

### 📐 19 Conversion Categories
Weight, FX & Crypto, Timezone (80 Regions), Gold Price, Baking Ingredients, Length, Area, Volume, Weather & AQI, Speed, Time, Data, Energy, Pressure, Power, Fuel Consumption, Angle, Force, Torque.
